# dugite v2.0.11

Consensus-liveness hotfix on top of v2.0.10. **Recommended upgrade for all nodes.**

## Fix — future-block clock-skew wedge (consensus-critical)

A block whose slot was even ~1 second ahead of the node's wall-clock was rejected
by Praos header validation with **zero clock-skew tolerance** and then
**permanently marked invalid**, causing the node to refuse the entire canonical
chain built on it (`StoreButDontChange` cascade) — a permanent chain wedge until
restart. Live-reproduced on preview (block 4396461 arrived ~1 slot early; on
restart the same block validated fine, proving the false-reject).

This matches Haskell `Ouroboros.Consensus.MiniProtocol.ChainSync.Client.InFutureCheck`,
where `defaultClockSkew = 2 seconds` and a from-the-future header is **never**
added to the invalid set (deferred within skew; peer disconnected beyond it).

- `dugite-consensus`: `CLOCK_SKEW_SLOTS = 2`; both future-block checks now allow
  `header.slot <= current_slot + 2` (2 s = 2 slots at 1 s/slot). Byte-exact at
  the boundary (N+1, N+2 accepted; N+3 rejected).
- `dugite-node`: a `FutureBlock` no longer routes through the permanent-invalid
  path — the fork is rolled back to its parent **without** blacklisting, so the
  block is re-applied automatically once the wall-clock reaches its slot
  (self-heal). All other (crypto/ledger) failures remain permanent as before.

Verified: full `just check` green; consensus-critical adversarial review GO
(the no-blacklist change turns a permanent wedge into self-recovery; the
per-worker fetch dedup + non-destructive rollback rule out any re-fetch loop).

Validation: this release line forged blocks **4396281** and **4396420** (the
latter carrying 2 txs) that were confirmed on the preview canonical chain
(Koios-verified).

### Known follow-up (non-blocking)
For exact Haskell parity, a peer that sends a *beyond-skew* block should be
disconnected (`InFutureHeaderExceedsClockSkew`) rather than silently rolled
back. Not exploitable today (fetch dedup prevents churn); tracked for a later
release.
