## Dugite v2.3.0

Backlog sweep: eleven issues closed (#914–#924). Two are byte-exact ledger/LSQ
divergences, one is a remotely-triggerable connection leak, and the rest are
correctness hygiene plus a class of harness defect that made test suites report
success while measuring nothing.

> ⚠️ **This is a re-sync release.** `SNAPSHOT_VERSION` moves 30 → 31 because the
> new per-era protocol-parameter fields are embedded in every serialized ledger
> snapshot. Existing databases replay their chunks on first restart. Pre-v2.1.0
> Mithril DBs still need a full `mithril-import`.

### Ledger / consensus correctness

- **#919 — per-era min-UTxO dispatch.** dugite applied exactly one min-UTxO
  formula — Babbage's `(160 + size) × coinsPerUTxOByte` — in *every* era,
  because `ada_per_utxo_byte` is seeded from the Alonzo genesis at startup
  regardless of the chain's era. Confirmed-on-chain mainnet Shelley
  transactions were rejected with `OutputTooSmall { minimum: 1051640, actual:
  1000000 }`. Now dispatched on protocol version, matching Haskell's per-era
  `getMinCoinTxOut`: flat `minUTxOValue` for Shelley/Allegra, Mary
  `scaledMinDeposit`, Alonzo `utxoEntrySize × coinsPerUTxOWord`, Babbage+
  unchanged. Also fixes PPU key 15 (decoded then dropped) and key 17, which
  means `coinsPerUTxOWord` before Babbage and `coinsPerUTxOByte` after.

- **#922 — `GetProposals` served the live proposal set.** Haskell's
  `queryProposals` never reads `cgsProposals`; it reads the DRep pulser's
  frozen `dpProposals`/`psProposals`, refreshed once per epoch boundary by
  `setFreshDRepPulsingState`. Mid-epoch submissions were therefore visible from
  dugite and not from cardano-node at the same tip. Now answers from the same
  frozen snapshot introduced for #903 — one mechanism, two bugs.
  `GetGovState`'s embedded `cgsProposals` correctly stays live.

- **#914 — invalid `prev_action_id` no longer silently dropped on apply.**
  Canonical `Conway.Rules.Gov` fails the transaction (`failBecause`); the code
  carried a comment claiming the opposite. Reaching that branch on ApplyOnly
  means governance state already diverged (the #898 shape), so it now hard
  errors at the point of divergence instead of stranding a deposit and skewing
  every reward that epoch.

### Networking

- **#924 — failed handshakes leaked the connection.** The mux task owns the
  `TcpBearer`, and the handshake-failure early return dropped its `JoinHandle`,
  which *detaches* a tokio task rather than aborting it. The socket stayed open
  for the process lifetime. Remotely triggerable by an unauthenticated peer —
  one malformed handshake per socket — and it defeated the inbound connection
  cap, since leaked sockets are never registered and so never counted. Verified
  against cardano-node 11.0.1 on the same host: it closes all five malformed
  handshake cases, dugite closed none.

- **#920 — trusted-only clamp now demotes, not just blocks.** Peers established
  during a CaughtUp period that later regressed stayed established, so the HAA
  closure could still fail. The governor now demotes untrusted established
  outbound peers every tick the clamp holds, with a one-shot sweep on the
  regression edge and a register-time gate closing the mid-handshake race.

- **#915 — canonical GOV tag-8 rejections.** `InvalidPrevGovActionId` now
  encodes as `ConwayGovFailure` (Ledger tag 3) / GOV tag 8 carrying the full
  `ProposalProcedure`, instead of a generic reason. Confirmed on the wire:
  `cardano-cli` decodes dugite's frame and renders the entire procedure in the
  same shape cardano-node produces.

### Test-harness integrity

Five of the eleven issues shared one shape — a check reporting success while
measuring nothing.

- **#923** — `adv_send_expect_close` returned PASS when `socat` was missing, so
  every adversarial N2N case in `protocols/01-07` "passed" without sending a
  byte on any host without socat (macOS by default). **This is what surfaced
  #924.** Adversarial results recorded on socat-less hosts before this release
  should be treated as unverified.
- **#918** — three tx-zoo scripts skipped structurally on every run. Now vendor
  a stdlib raw-socket writer and a CBOR splicer; `run-all.sh` classifies
  environmental vs state skips and gains `--strict-skips`.
- **#916** — the release-report generator counted the substring `error`, so
  `error=` fields on INFO lines showed thousands of errors on a clean run.
  Level counting is now shared with the analyzer, with an agreement test.
- **#917** — the forge-stall predicate was a ~3%-per-sample coin flip on a
  single-forger devnet. It now accumulates a Praos-derived p99.9 gap budget.
- **#921** — nextest gained a `slow-timeout` terminate-after backstop after a
  network outage left a ~10-minute suite wedged for 2h11m.
