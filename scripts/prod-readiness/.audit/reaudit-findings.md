Canonical Haskell (cardano-ledger, verified verbatim): Alonzo/Conway `TxWits` decCBOR uses `decodeSparseKeyed`/SparseKeyed with `txWitnessField n = invalidField n` for unrecognized keys; invalidField -> `Invalid n` -> `decodeCount (Invalid k) _ = invalidKey k`; `invalidKey k = cborError $ DecoderErrorCustom (typeRep <> " not a valid key:") (show k)` — a HARD decode failure. Thus a witness set carrying key 8 (or any unknown key) is rejected outright by cardano-node but accepted by dugite (returns Ok, field silently dropped). The witness set is not part of the tx hash (blake2b_256 of body bytes only), so dugite assigns the malformed tx the same tx-id and admits it — a genuine admission divergence across all three modern eras.
