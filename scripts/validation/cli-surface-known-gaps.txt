# Known, tracked gaps between cardano-cli's subcommand surface and
# dugite-cli's, checked by cli-surface-parity.sh (#1006).
#
# Format: <normalized command path><TAB><issue-number><TAB><disposition><TAB><reason>
# One entry per line. Blank lines and lines starting with # are ignored.
#
# <disposition> is REQUIRED and must be one of:
#   DEFERRED  — will implement eventually; tracked, not scheduled. A green
#               gate must not be able to hide the difference between "we
#               haven't gotten to it" and "we will never do this" — that
#               distinction was the whole reason this column exists (#1008).
#   WONTFIX   — deliberately excluded and not expected to change (dead
#               network, ceremony tooling superseded by this repo's own
#               devnet bootstrap, an era/feature that hasn't shipped, etc).
# cli-surface-parity.sh FAILS the gate if a MISSING entry's line has no
# disposition or an unrecognized one — see its `--- disposition audit ---`
# check. <reason> is free text (may itself contain tabs/spaces) and is
# REQUIRED too: every line must say SOMETHING, not rely on a blanket comment
# above an undifferentiated block. Mirrors the `SKIP_LIST` discipline in
# tests/conformance/src/upstream/ledger_rules_replay/mod.rs: "empty or every
# entry has a tracking issue" (CLAUDE.md) — extended here so entries also
# each carry their OWN disposition + reason, not just a shared issue number.
#
# The script separately fails on any listed entry that is no longer actually
# missing (a stale exemption — remove it).
#
# Originally 82 entries from cli-surface-parity.sh's first real run against
# cardano-cli 11.0.0.0 (97036a66bcf8c89f687ae57a048eecc0389977ef) — see #1008
# for the full triage. 10 closed by #1008's first implementation pass
# (2026-08-05: hash anchor-data/script/genesis-file, governance drep
# metadata-hash, version, stake-pool deregistration-certificate, stake-address

# further 25 closed by #1008's second implementation pass (2026-08-20, this

# (drep-stake-distribution, era-history, future-pparams, ledger-peer-snapshot,
# pool-state, ref-script-size, spo-stake-distribution, stake-pool-default-vote

# #1091 (2026-08-21) closed 9 of the 22 entries #1008 deferred: all 4
# cip-format cip-129 subcommands (CIP-0129 bech32 encoding, wired into

# `non-extended-key` (generic key-envelope transforms needing no BIP-39/HD

# in real cardano-cli 11.0.0.0 at all and moved to WONTFIX. The remaining 12
# — `debug log-epoch-state`, six BIP-39/ITN/cardano-address key-conversion
# commands, and three transaction fee/cost-estimation commands — stay
# DEFERRED with reasons updated to reflect what #1091's investigation
# actually found, not the original placeholder text.
